## Project Description

This project is a React frontend application built using Vite for the CommunityHub platform.  
The project demonstrates React fundamentals such as JSX, components, props, state management, event handling, controlled forms, and conditional rendering.



## Technologies Used

- React
- Vite
- JavaScript
- CSS3
- HTML5



## Features

- Functional React components
- JSX syntax
- Props for passing data
- useState hook
- Event handling
- Controlled forms
- Dynamic list rendering using `map()`
- Conditional rendering
- Basic CommunityHub frontend structure





## How to Run

### 1. Clone the repository


git clone https://github.com/marymacharia521-netizen/iyf-s10-week-08-marymacharia521-netizen.git


### 2. Navigate into the project folder


cd iyf-s10-week-08-marymacharia521


### 3. Install dependencies


npm install


### 4. Start the development server


npm run dev
